# Frontend

Frontend application for the WorkOrbit Project Management Tool.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Workflow

```text
User
  │
  ▼
Frontend Interface
  │
  ▼
REST API Requests
  │
  ▼
Backend Services
```

## Installation

```bash
npm install

npm run dev
```

Runs on:

```text
http://localhost:5173
```
